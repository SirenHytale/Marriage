## 💍 Marriage v2.2.0 - Update 6 Compatibility

No new features this time - 2.2 exists purely to keep Marriage running on the current Hytale server. Everything that shipped in 2.1 - the bond, the seven perks, vows, ring tiers, love letters, the menu - is unchanged.

**🔧 Compatibility**
- Updated for **Hytale Server 0.6.0-pre.13.1** (Update 6) - this release no longer runs on 0.5.x servers. Stay on **v2.1.0** if your server hasn't updated yet.
- Every command, perk, vow, ring tier and config value works exactly as it did in v2.1.0.

**⬆️ Upgrading**
Straight drop-in from 2.1.0 or earlier - your config and every existing marriage carry over untouched.
